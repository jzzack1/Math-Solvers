# Numerical Solution of the 1D Schrödinger Equation

This project solves the 1D time-independent Schrödinger equation
using a finite-difference Hamiltonian and matrix diagonalization.

## Features
- Harmonic oscillator potential
- Finite-difference kinetic energy operator
- Dirichlet boundary conditions
- Eigenvalue and eigenfunction computation
- Visualization of probability density

## Requirements
- numpy
- scipy
- matplotlib

## How to run
python schrodinger_solver.py
